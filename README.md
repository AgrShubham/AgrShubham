## Featured Engineering Projects

### 1. [Remote Trackpad & Gamepad Pro](https://github.com/AgrShubham/Remote-trackpad-app)
*Turn Smartphone into PC Trackpad, Gamepad & Keyboard*
- **Low-Latency UDP Streaming:** Architected an asynchronous UDP datagram pipeline over **Port 5002** delivering cursor deltas directly into Windows `user32.dll` via Win32 `SendInput` with **under 1ms execution latency**, eliminating TCP head-of-line blocking.
- **Kinetic Velocity Ballistics:** Engineered a mathematical acceleration model (`v_smooth = v_raw * (1.0 + min(2.5, v_raw * 0.6))`) with 0.1px deadband filtering, eliminating touchscreen digitizer jitter while preserving single-pixel precision.
- **Zero-Driver System Daemon:** Packaged a standalone 27MB Windows system tray executable using PyInstaller, eliminating the need for unsigned third-party kernel drivers or elevated administrative privileges.
- **Technologies:** `Python 3.11`, `React Native`, `TypeScript`, `UDP Sockets`, `Win32 API`, `Android SDK`

### 2. [Shree Mewa Commercial Platform](https://github.com/AgrShubham/ShreeMewa)
*Commercial Boutique & Gifting E-Commerce Store*
- **Production Web Application:** Architected and deployed a production full-stack web platform for a luxury dry fruits boutique using **React 19, TypeScript 5.8, Tailwind CSS v4, and Vite 6**.
- **WhatsApp Concierge Funnel:** Mitigated cart abandonment on high-value bespoke orders (₹25,000+) through an automated state-driven checkout pipeline dynamically serializing order configurations into deep-links.
- **Client-Side Lookbook Engine:** Implemented an instant offline PDF catalog generation engine leveraging dedicated CSS `@media print` stylesheets and Web Share API.
- **Technologies:** `React 19`, `TypeScript 5.8`, `Tailwind CSS v4`, `Vite 6`, `Web Share API`, `Schema.org JSON-LD`

### 3. [Remote Trackpad Web](https://github.com/AgrShubham/Remote_trackpad_web)
*Turn Smartphone Browser into PC Mouse (Zero Installation)*
- **Zero-Install Input Server:** Engineered a lightweight Flask and Socket.IO server allowing mobile web browsers on local Wi-Fi to control desktop cursor navigation with real-time WebSocket synchronization.
- **Acoustic Feedback Synthesis:** Synthesized real-time mechanical switch acoustics using the **Web Audio API** (1750Hz tactile snap + 220Hz bottom-out clack), bypassing iOS Safari system-level vibration restrictions.
- **Touch Event Batching:** Batched high-frequency touch coordinate deltas with `requestAnimationFrame`, reducing WebSocket network throughput by **40%** while maintaining smooth 60fps tracking without layout thrashing.
- **Technologies:** `Python`, `Flask`, `Socket.IO`, `JavaScript (ES6+)`, `Web Audio API`, `Pynput`
